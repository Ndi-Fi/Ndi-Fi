# Support

This page is the entry point for help with Ndi-Fi. There is no official user
support chat or dedicated support email yet; please use the channels below.

## Documentation

Start with the [protocol overview](README.md) and the
[documentation index](docs/). Contributors should start with the
[contributor onboarding guide](docs/ONBOARDING.md). To run the full local stack
(EVM + Stellar + web) in one go, see [docs/LOCAL_STACK.md](docs/LOCAL_STACK.md).
The [developer guide](DEVELOPMENT.md) covers local build and test commands, and
the [Stellar guide](stellar/README.md) covers the Soroban implementation.

## Security reports

**Never file a public issue for a suspected vulnerability.** Follow
[SECURITY.md](SECURITY.md#reporting-a-vulnerability) so reports reach the
maintainers privately.

## Contact maintainers

For questions that are not answered in the documentation, contact a repository
maintainer through their public GitHub profile linked from the
[Ndi-Fi repository](https://github.com/Ceejaytech25/Ndi-Fi). Include the network,
contract or component involved, and the steps needed to reproduce the problem.

Contributors can also read [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow
and branch rules before opening a pull request.
